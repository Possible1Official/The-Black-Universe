# Asset pipeline

## Current release
The ship, universe forge, planets, panels, floor detail and articulated crew are procedural. No external character asset is included. Crew are temporary android meshes, not realistic Mixamo humans. Runtime requires no token. All procedural art is generated by this project. Nysa ground color, normal and roughness maps are generated from deterministic periodic noise (128×128); no external terrain photograph or texture pack is included.

## MixamoHarvester
Source: https://github.com/paulpierre/MixamoHarvester (MIT tooling), pinned revision `0f9a38aa15a79110016a0a1df15f0863c8dd9e12`. Mixamo asset terms are separate from the tool's license; inspect them before distribution.

A local OCR reconstruction of the three supplied screenshots was probed against the Mixamo catalog on 2026-10-13. The service returned **HTTP 500**. This establishes neither a valid credential nor an expired one. No assets were acquired, and no credential was retained. Exact screenshot reconstruction may contain OCR errors. A valid token provided to a local process remains required. Later attempts to open the shared browser for Adobe sign-in were blocked before login by missing shared-browser session authorization; no Adobe verification challenge was reached and no account credentials were retained in project files.

`python scripts/mixamo-import.py --catalog` uses pinned upstream catalog requests. `--character ID --motion Idle --motion Walking` invokes upstream export/download operations for a bounded selection. Install Python dependencies in a local virtual environment: `pip install requests tqdm tenacity`. Supply `MIXAMO_BEARER_TOKEN` through your local environment or secret manager, never shell history, tracked files, or browser code. The importer and upstream pipeline need verification against a working Mixamo account before they can be considered complete.
